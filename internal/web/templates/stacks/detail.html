Preview project file names and sizes. Ignored and hidden files may be included; file contents can contain secrets. This preview is not an atomic snapshot and does not transfer files or authorize deployment.

Preview scope and limits

Local projects include Brine's meta.json; Git projects use the repository root. Git subfolder previews are unavailable.

Limits: 1,000 files, 2,000 entries, 32 levels, 4 MiB per file and 16 MiB total. Exceeding a limit fails the entire preview.

  • Entries named .git are omitted. Symlinks and special files are rejected.
  • Ignored, untracked and hidden files are included; .gitignore is not honored. Files such as .env and keys may be included.
  • Regular files with hard links and files under mounted subdirectories are included; these are not detected or filtered.
  • Project root ancestors and other processes running as the same user must be trusted; this is not a filesystem sandbox.
  • Empty directories and file modes are not preserved.
  • Concurrent changes mean this is not an atomic snapshot; a later preview may differ.
  • Preview does not transfer files or authorize deployment; it does not confirm immutable snapshot bytes.
