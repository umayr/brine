# Unmounted restore-as-new review seam

The private prepare function has no route or production adapter. Separate
explicit local archive-read consent binds the cookie-authenticated operator and
session to one object, active registry enrollment, target, stack, and exact
scope. Its in-memory approval is short-lived, revocable, and consumed when the
fresh review is created. It is checked before resolving/reading the object and
again before exposing the review. Missing or stale consent does not survive a
restart. The local read approval is never a transfer or apply confirmation.

A separate gate must authorize access and attest that no unresolved current
operation blocks the new review. The gate is required at prepare, before
staging and before any new intent or apply. Unknown, partial, and intent-only
history do not qualify as a previous successful configuration.
A historical success does not prove current admission, health, or grant status.

Prepare requires a successful terminal receipt under the same exact target,
stack, scope and authority revision (no rotation continuity). It places exact
archived bytes in the existing bounded, expiring project review store, not the
current workspace. Before staging, a fresh verified connection and explicit
transfer confirmation are required. The current provider must confirm the
manifest and produce a fresh checked create/update preview under the same
journal. A changed journal can leave a staged copy but cannot lead to an apply.
A second explicit approval authorizes that current selection only. The existing
remote Git overlap and durable intent/unknown-marker gates still apply.

The new record has independent local object, attempt, and provider request IDs
and an encrypted prior-object reference. The old record is not updated. No
provider call happens on reopen, no old request is replayed, and a failed or
ambiguous submission is not retried. No volumes, databases, images, or engine
state are rolled back. Actual authorization and status credential provisioning
are outside this seam; generated fixtures supply no product authority.
